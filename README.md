# 🔥 Elfathrojeck Terminal

Terminal-style web interface inspired by Termux + Hacker Aesthetic.

## Features
- Matrix rain background
- Animated typing "Welcome to elfathrojeck"
- Sound effect (Welcome voice)
- Interactive command input (help, whoami, clear, exit, matrix)
- Fully responsive
- Pure HTML / CSS / JS (no framework)

## Demo
Buka `index.html` di browser atau deploy ke GitHub Pages.

## Commands
```
help      → list command
whoami    → show identity
clear     → clear terminal
matrix    → boost matrix
exit      → logout
```
